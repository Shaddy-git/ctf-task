# CTF-Polytech-2026 | База задач

Добро пожаловать в официальный репозиторий с учебными задачами для CTF-сообщества Московского Политеха (проект Команда CTF [2]).

## О проекте
Этот репозиторий создан для хранения, систематизации и проверки учебных задач по информационной безопасности. Наша цель -- создать базу из 50+ качественных заданий в 5 категориях для подготовки студентов к участию во внешних соревнованиях и внутренних турнирах.

## 📂 Структура репозитория

Задачи разделены по категориям:
*   `web/` -- Уязвимости веб-приложений (SQLi, XSS, SSRF, обход аутентификации и т.д.)
*   `crypto/` --  Криптография и шифры (классические шифры, RSA, AES, атаки на хэши)
*   `reverse/` -- Реверс-инжиниринг (анализ бинарных файлов, обфускация)
*   `pwn/` - Бинарная эксплуатация (Buffer Overflow, ROP, форматные строки)
*   `forensics/`  Компьютерная криминалистика (анализ трафика, памяти, стеганография)
*   `osint/` -- Поиск по открытым источникам

## Формат задачи
Каждая задача находится в отдельной папке и должна содержать:
1.  **`README.md`** (или `task.md`) - описание задачи, входные данные и формат флага.
2.  **`solve/`** - папка с файлом-решением (скрипт, эксплойт или пошаговый разбор) и флагом.
3.  **`files/`** - папка с исходными файлами, которые выдаются участникам (архивы, бинарники, картинки).

##  Правила для авторов задач
1.  **Проверка:** Каждая задача перед добавлением в репозиторий проходит обязательное ревью (проверка работоспособности, актуальности и отсутствия ошибок).
2.  **Уникальность:** Приветствуется создание собственных задач или адаптация открытых источников (с указанием оригинального автора).
3.  **Сложность:** Задачи должны быть разделены на уровни (Easy, Medium, Hard).
4.  **Флаг:** Формат флага должен быть единым: `polytech{...}`.
